When designing a skill-gap-filling prompt for application time, ask the user for evidence ("where did you use X?", tied to an existing work-history/education/project entry) rather than a plain yes/no confirmation ("do you have X?").

## Why
A yes/no prompt that supplies the desired answer in the same breath creates an incentive to overclaim a skill just to pass a filter, which fails later at interview; requiring evidence makes the claim honest by construction and produces material for a résumé bullet that actually evidences the skill. · How to apply: Write any such confirmed skill to the profile (not just one résumé), and never pre-tick or phrase it as "add this to pass the filter."
