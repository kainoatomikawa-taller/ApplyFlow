For matching-only qualification fields (security clearance, degree) leaving them blank never disqualifies a candidate (hard filters return early on unset), but filling them in can only ever remove jobs from the match list, never add any.

## Why
This is a deliberate consequence of the "unknown never held against candidate" principle — a user with no clearance should leave clearance blank rather than pick a low tier, since a low tier would start filtering out higher-cleared roles rather than revealing more.
